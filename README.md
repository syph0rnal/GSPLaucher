# GSPLaucher

Браузерная игровая консоль с интерфейсом, вдохновлённым PlayStation 3 XMB.

**Сайт:** https://syph0rnal.github.io/GSPLaucher/

## Что внутри

- Полностью новая оболочка XMB: категории, список игр, карточка выбранной игры и экран запуска.
- Анимированные фоновые волны, плавное выделение пунктов, заставка включения и адаптация под небольшие экраны.
- Собственная игровая система на Canvas без сторонних игровых движков.
- Аркады: Змейка, Pong, Neon Breaker, Space Defense, Astro Salvage (космическая аркада), Neon Runner.
- Логические игры: Block System (тетрис), 2048, Сапёр, Circuit Link (восстановление энергетической цепи), Memory Pulse (тренировка памяти на последовательностях) и Echo Maze (исследование лабиринта с эхолокацией).
- Платформер: Gravity Shift — сбор энергетических ядер с переключением гравитации.
- Управление клавиатурой, пауза, возврат в меню и перезапуск партии после завершения.
- Фоновая музыка из `music/fone.mp3` с повтором, синтезированная заставка включения и звуковые сигналы интерфейса.
- Переключатель звука управляет фоновой музыкой и звуковыми эффектами.
- Автоматическая пауза при переключении вкладки браузера.
- Настройки звука и языка.

## Управление оболочкой

| Клавиши | Действие |
| --- | --- |
| ← / → | Переключить категорию |
| ↑ / ↓ | Выбрать пункт |
| Enter | Открыть или запустить |
| Esc | Вернуться в меню |

Управление конкретной игры показывается перед запуском и в игровом окне. В Circuit Link используйте стрелки или WASD для выбора сегмента, Enter или Space для поворота, R для сброса головоломки. В Memory Pulse запоминайте подсветку четырёх панелей, выбирайте их стрелками или WASD и подтверждайте Enter/Space; доступен также ввод мышью. В Gravity Shift используйте A/D или стрелки для движения, Space для прыжка, Q/E для смены гравитации и R для сброса. В Echo Maze перемещайтесь стрелками или WASD, нажимайте Space для эхолокационного импульса и R для сброса; соберите три осколка и доберитесь до выхода. В Block System Space выполняет мгновенное падение фигуры. В Сапёре первый открытый сектор и его соседние клетки безопасны.

## Запуск локально

Откройте `index.html` в современном браузере или запустите любой локальный HTTP-сервер в корне проекта.

## Технологии

HTML, CSS, JavaScript и Canvas 2D. Сборка и установка зависимостей не требуются.
