# GSPLaucher

**GSPLaucher** — это браузерная игра, которая имитирует лаунчер PlayStation 3.

Проект сделан на HTML, CSS и JavaScript. По дизайну здесь смешаны интерфейс PS3 и визуальный стиль Сбербанка примерно 2018 года. Проект участвует в конкурсе компании ITOP.

## Что есть

- Интерфейс в стиле PS3 (XMB).
- Меню для выбора игр.
- Запуск игр прямо в браузере.
- Настройки консоли и звука.
- Сохранение настроек.
- Адаптация интерфейса под разные размеры экрана.

## Как запустить

1. Скачай репозиторий.
2. Открой папку проекта.
3. Запусти файл `index.html` в браузере.

## Технологии
