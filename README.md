# GSPLaucher

**GSPLaucher** — браузерная игровая консоль с интерфейсом, вдохновлённым PlayStation 3 XMB.

**Открыть консоль:** [syph0rnal.github.io/GSPLaucher](https://syph0rnal.github.io/GSPLaucher/)

## Возможности

- Главное меню в стиле XMB: горизонтальные категории и вертикальный список игр.
- Анимированный сине-голубой фон с плавными волнами.
- Векторные SVG-значки вместо эмодзи.
- Звуки включения, навигации, подтверждения, возврата и игровых событий.
- 20 известных аркадных игр, включая «Танчики», Super Mario, Contra, Sonic, Tetris и Pac-Man.
- Режимы для одного и двух игроков там, где игра это поддерживает.
- Настройки громкости, музыки, звуков интерфейса, полноэкранного режима и языка.
- Русский язык по умолчанию; английский можно выбрать в настройках.
- Сохранение настроек и списка недавно запущенных игр.
- Управление клавиатурой и адаптация под мобильные экраны.

## Запуск локально

1. Скачайте репозиторий.
2. Откройте папку проекта.
3. Запустите `index.html` в современном браузере.

Для корректной работы звука нажмите любую клавишу или коснитесь экрана при запуске.

## Управление

- **← / →** — переключение категорий.
- **↑ / ↓** — выбор игры или настройки.
- **Enter** — подтвердить / запустить.
- **Esc** — назад в меню.
- **P** — пауза во время игры.

Управление внутри игр отображается на экране запуска.

## Технологии

HTML, CSS, JavaScript, Canvas и Web Audio API. Сторонние библиотеки для основного интерфейса не требуются.
