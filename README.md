# GSPLaucher

Браузерная игровая консоль с интерфейсом, вдохновлённым PlayStation 3 XMB.

**Сайт:** https://syph0rnal.github.io/GSPLaucher/

## Что внутри

- Полностью новая оболочка XMB: категории, список игр, карточка выбранной игры и экран запуска.
- Анимированные фоновые волны, плавное выделение пунктов, заставка включения и адаптация под небольшие экраны.
- Собственная игровая система на Canvas без сторонних игровых движков.
- Аркады: Змейка, Pong, Neon Breaker, Space Defense, Neon Runner.
- Логические игры: Block System (тетрис), 2048 и Сапёр.
- Управление клавиатурой, пауза, возврат в меню и перезапуск партии после завершения.
- Синтезированная звуковая заставка включения и звуковые сигналы интерфейса без внешних аудиофайлов.
- Автоматическая пауза при переключении вкладки браузера.
- Настройки звука и языка.

## Управление оболочкой

| Клавиши | Действие |
| --- | --- |
| ← / → | Переключить категорию |
| ↑ / ↓ | Выбрать пункт |
| Enter | Открыть или запустить |
| Esc | Вернуться в меню |

Управление конкретной игры показывается перед запуском и в игровом окне.

## Запуск локально

Откройте `index.html` в современном браузере или запустите любой локальный HTTP-сервер в корне проекта.

## Технологии

HTML, CSS, JavaScript и Canvas 2D. Сборка и установка зависимостей не требуются.
